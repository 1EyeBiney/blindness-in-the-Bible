# Source: Berean Standard Bible, official text

- File: `bsb.txt`
- From: https://bereanbible.com/bsb.txt (linked from https://berean.bible/downloads.htm)
- Downloaded: 2 October 2026, with Brian's approval
- Licence: dedicated to the public domain on 30 April 2023. "All uses are freely permitted."
  (https://berean.bible/terms.htm, read 2 October 2026). Attribution is appreciated but not required;
  this project gives it on every page.
- The publisher asks that only copies keeping the verbatim text carry the Berean name. This project
  quotes the text exactly as published and does not edit it.
- Shape: three header lines, then one verse per line as `Book C:V<TAB>text`. 31,102 verses, 66 books.
- The word "blind" in any form appears in 86 verses, the same count as in the Accessible Bible copy.

The copy in the Accessible Bible project (31,086 verses, quotation marks and apostrophes removed) was used
for the first draft of the catalog and has been replaced by this file.
