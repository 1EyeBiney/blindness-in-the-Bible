# Not By Sight

Studies on blindness in the Bible, by Brian Clark. "For we walk by faith, not by sight." (2 Corinthians 5:7)

Live site: https://blindnessinthebible.com

- `docs/CONCEPT.md` is the agreed concept and the decisions made so far.
- `docs/BRIAN_NOTES.md` holds Brian's own words, used for the personal sections.
- `data/catalog.csv` is the catalog of every passage about blindness.
- `src/build_catalog.py` rebuilds the catalog from the Berean Standard Bible text (kept in the Accessible Bible project).
- `src/build_site.py` builds the site from the catalog. `python -m pytest tests` checks both.

Scripture is from the Berean Standard Bible, which is in the public domain.
